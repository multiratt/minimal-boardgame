# ♟️ Minimal Checkers (หมากฮอสขาว-ดำ มินิมอล)

เว็บแอปพลิเคชันเล่นหมากฮอสสไตล์ **Monochrome Minimalist** คอนทราสต์ขาว-ดำ ดีไซน์เรียบหรู พร้อมแอนิเมชันการเดิน การกินทำลายเบี้ย และการเปลี่ยนร่างเป็นฮอส (King) รองรับทั้ง **กติกาไทย (8 ตัว • ฮอสบิน)** และ **กติกาสากล (12 ตัว • ฮอส 1 ก้าว)** พร้อมบอท AI 3 ระดับ และห้องเล่นสด 6 ห้อง + โหมดผู้ชม รันบน GitHub Pages ได้ 100%

🔗 **เข้าเล่นทันทีผ่าน GitHub Pages:** [https://multiratt.github.io/minimal-checkers/](https://multiratt.github.io/minimal-checkers/)

---

## ✨ จุดเด่นและคุณสมบัติใหม่ (Features)

* **🇹🇭/🌐 เลือกระหว่าง กติกาไทย vs กติกาสากล ได้ทันที:**
  * **กติกาไทย (Thai Rules):** วางเบี้ยฝ่ายละ **8 ตัว** (แถว 0-1 และ 6-7), เมื่อเบี้ยถึงแถวหลังสุดจะกลายเป็น **"ฮอสบิน (Flying King)"** เดินและบินกินได้ยาวตลอดแนวทแยงที่ไม่มีตัวขวาง และเลือกจอดที่ช่องว่างใดก็ได้หลังตัวที่กิน
  * **กติกาสากล (International Rules):** วางเบี้ยฝ่ายละ **12 ตัว** (แถว 0-2 และ 5-7), ฮอสเดินและกินทแยงหน้า-หลัง **ก้าวละ 1 ช่อง**
* **🖥️ แดชบอร์ดแบบ 2 คอลัมน์ (Side-by-Side Modern Layout):**
  * ฝั่งซ้าย: กระดานหมากฮอส 8x8 ขนาดใหญ่ ชัดเจน พร้อมแอนิเมชัน
  * ฝั่งขวา (Sidebar แผงควบคุมด้านข้าง):
    1. **กล่องสถานะผู้เล่นและตาเดิน (Players & Turn):** แสดงชื่อทั้ง 2 ฝั่ง จำนวนหมากที่เหลือ และไฟสถานะตาเดินปัจจุบัน
    2. **นาฬิกานับถอยหลังต่อตา (Digital Countdown Timer):** ตัวเลขนับถอยหลังขนาดใหญ่ 30 วินาที พร้อม Minimal Progress Bar
    3. **สถิติการกินหมาก (Captured Pieces Counter):** สรุปจำนวนหมากขาวและดำที่ถูกกิน
    4. **ปุ่มควบคุมเกม (Controls):** ยอมแพ้, เริ่มเกมใหม่, ออกสู่ล็อบบี้
    5. **กล่องสรุปกติกา (Active Rules Panel):** สรุปกติกาของโหมดที่เล่นอยู่ (ไทย หรือ สากล) ด้านข้างกระดานอย่างชัดเจน
* **🌐 รองรับ 2 ภาษา 100% (Strict Bilingual Thai / English):**
  * สลับภาษา ไทย (TH) หรือ English (EN) ได้แบบ Real-time ทุกข้อความ เมนู สถานะห้อง กติกา และกล่องแจ้งเตือน โดยไม่มีภาษาปนกัน
* **🎬 Kinetic Animations (ระบบแอนิเมชัน):**
  * **ตอนเดิน:** ตัวหมากสไลด์แบบ Smooth Translation สู่ช่องเป้าหมาย
  * **ตอนโดนทำลาย:** ตัวหมากยุบตัวลง (Scale down) พร้อมเกิดคลื่น Shockwave วงแหวนกระจายตัวสลายหายไป
  * **การแปลงเป็นฮอส:** หมุน Flip 3D (360°), ขยายร่าง Pulse และปรากฏมงกุฎเรขาคณิต
* **🤖 บอท AI ปรับความยากได้ 3 ระดับ:**
  * **ง่าย (Easy) / ปานกลาง (Medium) / ยาก (Hard):** คำนวณผ่าน **Web Worker** แยกเธรด ลื่นไหล 60 FPS เสมอ
* **⚡ เล่นออนไลน์ 6 ห้อง & โหมดผู้ชมสด (Serverless 100% บน GitHub Pages):**
  * ไม่ต้องสมัครบัญชี ตั้งชื่อแล้วเล่นได้ทันที
  * แสดงสถานะห้องสด 1-6 และกด **"เข้าชมสด (Spectate)"** เพื่อดูการแข่งขันแบบ Real-time ได้ตลอดเวลา
* **🔊 เสียงสังเคราะห์ Procedural SFX (Web Audio API):**
  * เสียงคลิกเดิน, เสียงกิน, เสียงฮอส, เสียงติ๊กเตือนเวลา และเสียงชนะเกม เปิด/ปิดเสียงได้

## 💻 การติดตั้งและทดสอบในเครื่อง (Local Run)

```bash
git clone https://github.com/multiratt/minimal-checkers.git
cd minimal-checkers
python3 -m http.server 8080
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:8080` เพื่อเข้าเล่นได้ทันที
