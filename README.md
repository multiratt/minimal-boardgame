# ♟️ Minimal Board Games (หมากฮอส & หมากรุก มินิมอลขาว-ดำ)

เว็บแอปพลิเคชันเล่นบอร์ดเกมสไตล์ **Monochrome Minimalist** คอนทราสต์ขาว-ดำ ดีไซน์เรียบหรู ออกแบบแดชบอร์ด **100% Viewport Fit (กระดานใหญ่เต็มตา กรอบเวลาและกติกาพอดีหน้าจอ ไร้การเลื่อนจอ)** รวบรวมทั้ง **หมากฮอส (Checkers)** และ **หมากรุก (Chess)** ครบทั้งกติกาไทยและกติกาสากล:

1. **หมากฮอสไทย:** 8 ตัว • ฮอสบินยาวตลอดแนวทแยง
2. **หมากฮอสสากล:** 12 ตัว • ฮอสเดินและกินทแยง 1 ก้าว
3. **หมากรุกไทย (Makruk):** 16 ตัว • ขุน, เม็ด, โคน, ม้า, เรือ, เบี้ยหงายแถว 6 ตามกติกาไทยแท้
4. **หมากรุกสากล (Western Chess):** 16 ตัว • King, Queen, Rook, Bishop, Knight, Pawn ตามมาตรฐานสากล

🔗 **เข้าเล่นทันทีผ่าน GitHub Pages:** [https://multiratt.github.io/minimal-checkers/](https://multiratt.github.io/minimal-checkers/)

## ✨ จุดเด่นและการปรับปรุงใหม่ (Features & Enhancements)

* **🖥️ 100% Viewport-Fit Dashboard (ไม่ต้องเลื่อนหน้าจอ):**
  * กระดานหมากขยายขนาดใหญ่เต็มพื้นที่สายตาตามขนาดหน้าจอ (Dynamic Aspect Ratio)
  * แผงควบคุมด้านข้าง (สถานะผู้เล่น, นาฬิกานับถอยหลังดิจิทัล, หมากที่ถูกกิน, ปุ่มควบคุม, และกล่องสรุปกติกา) กระชับพอดีในหน้าจอเดียว
* **♟️ เพิ่มหมากรุก (Chess) ครบทั้ง 2 กติกา:**
  * **หมากรุกไทย (Makruk):** กฎการเดินและกินของ ขุน, เม็ด, โคน, ม้า, เรือ, เบี้ย และการหงายเบี้ยที่แถว 6 พร้อมการตรวจจับรุกฆาต/อับ
  * **หมากรุกสากล (Western Chess):** การเดินของ King, Queen, Rook, Bishop, Knight, Pawn และการรุกฆาต
* **🎬 Kinetic Animations (ระบบแอนิเมชัน):**
  * **ตอนเดิน:** ตัวหมากสไลด์แบบ Smooth Translation สู่ช่องเป้าหมาย
  * **ตอนโดนทำลาย:** หมากยุบตัว (Scale down) พร้อมเกิดคลื่นวงแหวน Shockwave กระจายตัวสลายหายไป
  * **การเลื่อนขั้น/แปลงร่าง:** หมุน Flip 3D (360°), ขยายร่าง Pulse และปรากฏสัญลักษณ์ใหม่
* **🤖 บอท AI ปรับความยากได้ 3 ระดับ:**
  * **ง่าย (Easy) / ปานกลาง (Medium) / ยาก (Hard):** ทำงานทั้งบนหมากฮอสและหมากรุก
* **🌐 รองรับ 2 ภาษา 100% (Strict Bilingual Thai / English):**
  * สลับภาษา ไทย (TH) หรือ English (EN) ได้แบบ Real-time ทุกข้อความ เมนู และชื่อตัวหมาก
* **⚡ เล่นออนไลน์ 4 ห้อง & แสดงประเภทหมาก & โหมดผู้ชมสด (Serverless 100% บน GitHub Pages):**
  * กระชับเหลือ 4 ห้องเพื่อการจับคู่ที่รวดเร็ว แสดงป้ายบอกประเภทหมากของแต่ละห้องในล็อบบี้แบบ Real-time
  * ซิงค์กติกาและประเภทหมากของผู้สร้างห้องให้ผู้เล่นที่เข้า Join และผู้ชมสดตรงกัน 100%
  * กด "เข้าชมสด (Spectate)" เพื่อดูการแข่งขันแบบ Real-time ได้ตลอดเวลา
* **📊 สรุปสถิติหลังจบเกม (Match End Statistics):**
  * แสดงเวลารวมทั้งเกม, เวลาเฉลี่ยต่อตาเดิน (Avg time per turn), จำนวนตาเดินทั้งหมด (Total moves แยกขาว/ดำ), จำนวนหมากที่ถูกกิน, และจำนวนครั้งที่เลื่อนขั้น/หงายหมาก
* **🔊 เสียงสังเคราะห์ Procedural SFX (Web Audio API):**
  * เสียงคลิกเดิน, เสียงกิน, เสียงเลื่อนขั้น, เสียงติ๊กเตือนเวลา และเสียงชนะเกม เปิด/ปิดเสียงได้

## 💻 การติดตั้งและทดสอบในเครื่อง (Local Run)

```bash
git clone https://github.com/multiratt/minimal-checkers.git
cd minimal-checkers
python3 -m http.server 8080
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:8080` เพื่อเข้าเล่นได้ทันที
